Create a premium, highly distinctive, production-quality website for a private dermatologist:

# DR. ABBASSI KHALED

## Dermatologist

This is a professional medical website for a private dermatology practice.

The objective is NOT to create a generic "doctor website".

The objective is to create a **strong visual identity and premium digital experience** that feels specifically designed for a distinguished dermatology practice.

The website should communicate:

* Medical expertise
* Trust
* Precision
* Cleanliness
* Modern dermatology
* Personal care
* Calmness
* Sophistication
* Premium private-practice positioning

The design must feel refined, memorable and intentional.

---

# 1. DESIGN CONCEPT

Build the visual identity around:

**SKIN + PRECISION + LIGHT + CLINICAL ELEGANCE**

The design language should combine:

* Modern medical aesthetics
* Editorial luxury
* Minimalism
* Soft natural imagery
* Clinical precision
* Sophisticated typography
* Generous whitespace

The website should feel closer to a **high-end dermatology clinic brand** than a conventional medical website.

Avoid the typical visual language of:

* Generic hospitals
* Blue medical templates
* Huge medical crosses
* Stethoscope illustrations
* ECG graphics
* Excessive rounded cards
* Cheap gradients
* Excessive glassmorphism
* Generic stock-template layouts
* Overly colorful interfaces

Do not make the website look like a template.

---

# 2. VISUAL IDENTITY

Create a custom design system.

Use a restrained premium palette based on:

* Warm ivory / off-white
* Soft stone / light neutral
* Deep charcoal
* Muted botanical green or sage
* A very subtle warm accent

Do NOT use bright hospital blue as the dominant color.

Colors must be defined as reusable design tokens.

The visual system should remain elegant even if most photography is removed.

---

# 3. TYPOGRAPHY

Typography is extremely important.

Use:

### Display typography

A refined modern serif or elegant editorial display font for major headings.

### Interface/body typography

A clean modern sans-serif with excellent readability.

The combination should produce:

**medical authority + editorial sophistication**

Typography should create visual hierarchy through:

* Size
* Weight
* Spacing
* Line height
* Controlled contrast

Do not use decorative typography excessively.
